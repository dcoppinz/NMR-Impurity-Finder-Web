# NMR Impurity Finder — Free Installable Web App (PWA)

Created by **Davide Andrea Coppini** with ChatGPT assistance.

A literature-based solvent and impurity signal finder for **¹H** and **¹³C NMR**. Includes the Signal Match tool, the Browse Library, molecular structures, and schematic multiplet plots.

### Install

- **iPhone (Safari):** Open the published website → Share → Add to Home Screen → Add/Open as Web App.
- **Android (Chrome):** Open the website → browser menu → Install app or Add to Home screen.
- Launch the app once while online so its assets can be cached. The reference database is bundled and can then be used offline.

### Sources and limitations

This tool is for reference and educational use. Matching ppm values does not uniquely establish the identity of a compound. Follow the paper references and experimental spectra.

- Fulmer et al. (2010), https://doi.org/10.1021/om100106e
- Babij et al. (2016), https://doi.org/10.1021/acs.oprd.5b00417
- Gottlieb et al. (1997), https://doi.org/10.1021/jo971176v

**Notice:** The compiled reference dataset is included in the public HTML. Please review publisher rights and data reuse licensing before redistributing the data at scale.

This public repository contains only the distributable PWA, not the private Android/iOS source code.
